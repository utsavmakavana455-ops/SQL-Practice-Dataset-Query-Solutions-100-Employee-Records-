# SQL Employee Data Analysis Project

Developed and solved SQL practice problems using a custom employee dataset containing **100 records**. Used ChatGPT as an AI-assisted learning and productivity tool to explore SQL concepts, improve queries, and strengthen database management and analytical SQL skills.

## Topics Covered

* SQL Fundamentals
* Filtering and Sorting
* Aggregate Functions
* GROUP BY and HAVING
* Subqueries
* JOINs
* Window Functions
* Ranking Functions
* Date Functions
* Data Analysis Queries
* Interview-Oriented SQL Problems

## Questions Practiced

1. Find the highest-paid employee.
2. Find the second-highest salary.
3. Calculate the average salary by department.
4. Count the number of employees in each department.
5. Find employees hired after 2021-01-01.
6. Find the top 10 highest-paid employees.
7. Find employees earning above the company average salary.
8. Find the department with the highest average salary.
9. Rank employees by salary within each department.
10. Find employees earning between 70,000 and 85,000.
11. Find duplicate salaries.
12. Find employees with the same salary.
13. Find the third-highest salary.
14. Find employees earning more than their department's average salary.
15. Calculate the running total of salaries.
16. Find the highest-paid employee in each department.
17. Find the lowest-paid employee in each department.
18. Calculate the total salary for each department.
19. Find employees hired in the latest hiring year.
20. Find the top 2 highest-paid employees in each department.
21. Find the 5 employees with the earliest hire dates.

## Dataset

* **Table:** Employees
* **Records:** 100
* **Columns:** EmployeeID, Name, Department, Salary, HireDate
* **Departments:** IT, HR, Finance, Marketing

## Files
